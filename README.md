# Learning C

Learning C from scratch for GATE CSE 2027. Part of my journey to become a software engineer and cybersecurity specialist.

## Structure

```
learning-c/
├── src/
│   ├── 01-basics/           # Day 1-2: data types, variables, printf/scanf, operators, precedence, type conversion
│   ├── 02-control-flow/     # Day 3: if/else, nested if, switch
│   ├── 03-loops/            # Day 4: for, while, do-while, break, continue
│   ├── 04-functions/        # Day 5: functions, call by value, scope
│   ├── 05-recursion/        # Day 6: recursion
│   ├── 06-arrays/           # Day 7: 1D and 2D arrays
│   ├── 07-pointers/         # Day 8: pointer basics, pointer arithmetic
│   ├── 08-strings/          # Day 9: pointers with arrays, strings
│   ├── 09-structures/       # Day 10: structures, unions, storage classes
│   └── 10-dynamic-memory/   # Day 11: malloc, calloc, free, pointer to pointer, function pointers
├── gate-pyq/                # GATE previous year C questions, traced by hand (gate-YEAR-QNUM.c)
├── notes/                   # One markdown file of short notes per topic
├── Makefile
└── LICENSE
```

## How to build and run

```bash
make                        # compile everything in src/ and gate-pyq/ into bin/
./bin/01-basics/01-hello    # run a program
make clean                  # delete bin/
```

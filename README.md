# Learning C

My journey learning the C programming language — code, notes, and exercises, organized by topic.

## Structure

```
learning-c/
├── src/
│   ├── basics/            # variables, loops, functions, I/O
│   ├── pointers/           # pointers, memory, arrays
│   ├── data-structures/    # linked lists, stacks, queues, trees
│   └── algorithms/         # sorting, searching, recursion
├── Makefile
└── LICENSE
```

## How to compile and run

Compile a single file directly with gcc:

```bash
gcc src/basics/hello.c -o hello
./hello
```

Or use the Makefile to build everything in `src/`:

```bash
make
```
